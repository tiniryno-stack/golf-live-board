What a list or screen shows when there's nothing in it yet, or when a search finds nothing.

**Consumer provides:** a one-line headline, one line of help, and the one action that fixes it.

**Rules**
- A dashed `line` box (or the open screen) with a 56px `surface-2` icon circle, a `row` headline and a `body` help line in `text-muted`.
- First time: name what's missing and point at the main action ("No rounds yet" → New round).
- No results: quote what they typed, suggest a fix (spelling), and offer a way out ("Enter the scorecard yourself").
- Waiting on data (Board, Matches before any scores): show the real structure (teams, matchups) with "Waiting for the first scores" instead of zeros.
- Never a blank screen.
