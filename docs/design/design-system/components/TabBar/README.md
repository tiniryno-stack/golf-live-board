The bottom tab bar on every in-round screen: Enter, Matches, Board, Card, in that order.

**Consumer provides:** the active tab and the four destinations.

**Rules**
- A floating `surface-1` bar with a `line` border and `radius-2xl` corners, inset 12px from the screen edges and 10px from the bottom (plus the safe area).
- Each tab is 50px tall with a 20px line icon above a `small`-size label.
- The active tab is filled with `button` and its icon and label use `on-button`; others are `text-muted`.
- Setup screens have no tab bar; they end with a primary button instead.
