A small tinted, outlined chip naming a cart by letter, used in matchup rows, tee-group rows and custom matchup pickers.

**Consumer provides:** the cart letter and whether it's yours.

**Rules**
- 30px tall (44px when it's a tap target in the custom matchup picker), `radius-sm`, 1.5px outline and text in the cart color on its tint.
- Yours reads "A · You" in `cart-you-text`; others are just the letter.
- Write matchups as `[A · You] vs [C]   [B] vs [D]`, with "vs" in `text-muted`.
